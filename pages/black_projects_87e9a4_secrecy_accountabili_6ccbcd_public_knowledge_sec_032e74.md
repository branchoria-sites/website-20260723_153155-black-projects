## Introduction

Secret military and intelligence programmes inevitably create tension between national security and democratic [accountability]({{ 'accountability/' | relative_url }}). The key question is not whether every classified detail should become public. Instead, it is what citizens can reasonably expect to know without compromising the programme's effectiveness or putting lives, [intelligence sources]({{ 'intelligence-sources/' | relative_url }}) or military capabilities at risk.



<img src="{{ "/assets/images/black_projects_87e9a4_secrecy_accountabili_6ccbcd_public_knowledge_sec_032e74-Illustration-1-dark.svg" | relative_url }}" alt="Public Disclosure illustration 1" data-theme-src-dark="{{ "/assets/images/black_projects_87e9a4_secrecy_accountabili_6ccbcd_public_knowledge_sec_032e74-Illustration-1-dark.svg" | relative_url }}" data-theme-src-light="{{ "/assets/images/black_projects_87e9a4_secrecy_accountabili_6ccbcd_public_knowledge_sec_032e74-Illustration-1-light.svg" | relative_url }}" loading="eager" decoding="sync" fetchpriority="high">

In democratic systems, secrecy is generally considered more legitimate when it is limited to operational details while broader questions remain open to public scrutiny. Citizens may not know exactly how a surveillance system works, how a stealth aircraft achieves its [radar signature]({{ 'radar-signature/' | relative_url }}) or where a covert capability is deployed. They can, however, expect governments to explain why such programmes exist, under what legal authority they operate, how much public money they consume in broad terms and what institutions are responsible for overseeing them. This distinction allows governments to protect genuine security interests without asking the public to accept unlimited secrecy on [trust]({{ 'trust/' | relative_url }}).<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;req=granuleid%3AUSC-prelim-title50-section3348" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-title">U.S. Code</span><span class="citation-popover-snippet">U.S. Code</span></span></span>

* **The programme's broad purpose**, such as developing advanced aircraft, improving cyber defence or collecting foreign intelligence.
* **Its legal basis**, including the legislation, executive authority or policy framework that permits it.
* **Approximate costs or overall budgets**, even if detailed line items remain classified.
* **Which departments are responsible** for managing and supervising the programme.
* **The existence of oversight mechanisms**, including parliamentary or congressional committees, inspectors general, auditors or courts where applicable.
* **General procurement milestones**, such as whether a capability is in research, testing or operational service, without revealing sensitive technical characteristics.

This type of disclosure allows public debate over national priorities while protecting operational effectiveness. For example, the United States publicly releases the aggregate budget for the National Intelligence Program even though individual intelligence activities remain classified. Congress required this disclosure to improve fiscal accountability without exposing sensitive capabilities.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?req=%28title%3A50+section%3A3306+edition%3Aprelim%29" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">U.S. Code</span></span></span>

## Why purpose, cost and legal authority matter

Knowing that a programme exists is only the beginning of democratic accountability. Citizens also need enough information to judge whether it deserves continued public support.

### Purpose allows public debate

A democracy cannot meaningfully debate defence priorities if entire categories of activity are hidden indefinitely. Explaining that a classified programme develops missile defence, protects military [satellites]({{ 'satellites/' | relative_url }}) or detects foreign cyber intrusions allows voters and legislators to discuss national priorities without learning sensitive engineering details.

Public understanding of purpose also helps prevent "mission creep", where programmes gradually expand beyond their original objectives without meaningful scrutiny.

### Cost enables financial accountability

Secret programmes are funded with public money. While publishing detailed contracts or component costs may reveal sensitive information, governments can often disclose total programme expenditure or aggregate spending within classified portfolios.

This enables legislatures, auditors and the public to ask important questions:


<div class="content-enhancement content-enhancement--comparison" markdown="1">

* Is the programme affordable?
* Has it exceeded its approved budget?
* Is it delivering value compared with alternatives?
* Has funding increased substantially without public explanation?

</div>

Many democracies separate classified operational information from broader budget oversight precisely because financial accountability does not necessarily require revealing technical secrets.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;req=granuleid%3AUSC-prelim-title50-section3348" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">U.S. Code</span></span></span>

### Legal authority limits arbitrary power

Perhaps the most important public disclosure concerns legality.

Citizens should be able to know:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* which laws authorise the programme;
* which executive agencies are responsible;
* whether courts have any oversight role;
* what privacy or civil-liberty protections exist where applicable; and
* which elected representatives receive classified briefings.

</div>

Even when operational details remain secret, governments can publish the legal framework governing intelligence collection, surveillance authorities and oversight arrangements. The Office of the Director of National Intelligence, for example, publishes information explaining oversight structures, privacy protections and the roles played by Congress, inspectors general, the Department of Justice and specialised courts for certain intelligence activities.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.intelligence.gov/foreign-intelligence-surveillance-act/overseeing-section-702" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: intelligence.gov">[Intelligence]</a><span class="citation-popover" role="note"><span class="citation-popover-source">intelligence.gov</span><span class="citation-popover-title">Overseeing Section 702</span><span class="citation-popover-snippet">Overseeing Section 702...</span></span></span>

## How oversight works without full public disclosure

A common misconception is that either everyone knows everything or no accountability exists. In practice, democratic systems often rely on layered oversight.

For highly classified programmes, oversight may include:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* selected parliamentary or congressional committees with appropriate security clearances;
* inspectors general who can investigate fraud, abuse and misconduct;
* government auditors reviewing financial management;
* executive officials responsible for approving classification decisions;
* specialised judicial review for some intelligence activities; and
* periodic reporting requirements established by law.

</div>

In the United States, federal law requires departments operating Special Access Programs to report information about those programmes to designated congressional oversight committees. Reports typically include descriptions, funding information and programme status even though the same information is not released publicly.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;req=granuleid%3AUSC-prelim-title50-section3348" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">U.S. Code</span></span></span>

The principle is that secrecy from foreign governments should not automatically mean secrecy from every institution responsible for constitutional oversight.

## Where public transparency must stop

Legitimate transparency has practical limits. Some information remains classified because disclosure would directly reduce national security rather than simply embarrass officials.

Information that commonly requires protection includes:

* precise technical specifications;
* intelligence sources and human assets;
* [surveillance methods]({{ 'hidden-methods/' | relative_url }});

<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* cryptographic systems;
* operational plans;
* vulnerabilities in military equipment;
* covert collection techniques; and
* information that would reveal how capabilities could be defeated.

</div>

Even seemingly minor details may become valuable when combined with other publicly available information. Intelligence analysts refer to this as the "mosaic effect": individual fragments appear harmless, but together they can reveal a classified capability or operational pattern.

For this reason, governments frequently release only high-level descriptions while withholding the technical data that would allow adversaries to reconstruct the underlying system.



<img src="{{ "/assets/images/black_projects_87e9a4_secrecy_accountabili_6ccbcd_public_knowledge_sec_032e74-Illustration-3-dark.svg" | relative_url }}" alt="Public Disclosure illustration 3" data-theme-src-dark="{{ "/assets/images/black_projects_87e9a4_secrecy_accountabili_6ccbcd_public_knowledge_sec_032e74-Illustration-3-dark.svg" | relative_url }}" data-theme-src-light="{{ "/assets/images/black_projects_87e9a4_secrecy_accountabili_6ccbcd_public_knowledge_sec_032e74-Illustration-3-light.svg" | relative_url }}" loading="lazy" decoding="async" fetchpriority="low">

## The risk of overclassification

The existence of legitimate secrets does not mean every classification decision is justified.

Independent reviews, historians and former national security officials have long argued that governments sometimes classify information primarily to avoid political embarrassment, conceal administrative mistakes or reduce public scrutiny rather than to protect genuine security interests. Excessive secrecy can also make oversight more difficult by limiting information-sharing even within government.

Recognising this problem, intelligence agencies have adopted transparency principles intended to encourage disclosure whenever it can occur without harming national security. These policies acknowledge that public trust depends not only on protecting secrets but also on explaining government activities whenever safe to do so.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.dni.gov/index.php/ncsc-how-we-work/197-about/organization/office-of-civil-liberties-privacy-and-transparency" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: dni.gov">[Director of National Intelligence]</a><span class="citation-popover" role="note"><span class="citation-popover-source">dni.gov</span><span class="citation-popover-title">Director of National Intelligence</span><span class="citation-popover-snippet">Director of National Intelligence</span></span></span>

## What citizens should reasonably expect

A practical standard for democratic accountability is not complete openness but informed consent.

Citizens should normally expect governments to disclose:


<div class="content-enhancement content-enhancement--phrase-stack" markdown="1">

* **why** a secret programme exists;
* **which public interest** it serves;
* **its broad cost** to taxpayers;
* **its legal authority**;
* **who oversees it**; and
* **whether independent institutions can investigate misconduct**.

</div>

By contrast, citizens should not normally expect immediate disclosure of technical designs, operational tactics, intelligence sources or other details whose release would directly undermine the capability itself.

This distinction preserves an essential democratic principle: governments may legitimately keep operational secrets, but they should not keep secret the fact that public money is being spent under legal authority and subject to meaningful oversight.

  }
  function inferFromLocale() {
    var matches = localeMatches();
    return matches.exact || matches.language || '';
  }
  function inferFromTimezone() {
    var tz = '';
    try { tz = String(Intl.DateTimeFormat().resolvedOptions().timeZone || ''); } catch (err) {}
    if (!tz) return '';
    for (var i = 0; i< timezoneRules.length; i += 1) {
      var rule = timezoneRules[i] || {};
      try {
        if (new RegExp(rule.pattern).test(tz)) return rule.market;
      } catch (err) {}
    }
    return '';
  }
  function inferMarket(available, options) {
    available = Array.isArray(available) ? available : [];
    options = options || {};
    var storageKey = options.storageKey || 'phoenix-affiliate-market';
    try {
      var saved = window.localStorage && localStorage.getItem(storageKey);
      if (saved && available.indexOf(saved) >= 0) return saved;
    } catch (err) {}
    var timezoneMarket = inferFromTimezone();
    if (timezoneMarket && available.indexOf(timezoneMarket) >= 0) return timezoneMarket;
    var localeMarkets = localeMatches();
    if (localeMarkets.exact && available.indexOf(localeMarkets.exact) >= 0) return localeMarkets.exact;
    if (localeMarkets.language && available.indexOf(localeMarkets.language) >= 0) return localeMarkets.language;
    if (options.defaultMarket && available.indexOf(options.defaultMarket) >= 0) return options.defaultMarket;
    return available[0] || '';
  }
  window.PhoenixAffiliateLocation = {
    normalize: normalize,
    inferMarket: inferMarket,
    inferFromLocale: inferFromLocale,
    inferFromTimezone: inferFromTimezone
  };
})();
