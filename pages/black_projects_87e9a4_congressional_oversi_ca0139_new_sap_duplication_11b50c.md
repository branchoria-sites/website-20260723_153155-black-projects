## Introduction

One of the least discussed features of congressional oversight for highly classified US defence programmes is that new Special Access Programs (SAPs) must now be justified not only on security grounds but also against the risk of unnecessary duplication. The reporting requirement reflects a practical concern: extreme [compartmentation]({{ 'compartmentation/' | relative_url }}) can protect sensitive capabilities, yet it can also make it difficult for decision-makers to recognise when multiple organisations are pursuing similar technologies or missions in isolation. Rather than assuming every new compartmented programme is unique, Congress requires the Department of Defense (DoD) to explain why a new SAP deserves exceptional secrecy and to identify comparable programmes or technologies already in existence.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.law.cornell.edu/uscode/text/10/119" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: law.cornell.edu">[Legal Information Institute]</a><span class="citation-popover" role="note"><span class="citation-popover-source">law.cornell.edu</span><span class="citation-popover-title">Legal Information Institute10 U.S. Code § 119</span><span class="citation-popover-snippet">Special access programs: congressional oversight &#124; U.S. Code &#124; US Law &#124; LII / Legal Information Institute...</span></span></span>

This mechanism does not eliminate hidden duplication, nor does it require programmes to be merged. Instead, it creates a formal checkpoint before another compartmented programme expands, giving congressional defence committees an opportunity to ask whether the proposed work fills a genuine capability gap or simply recreates work already taking place elsewhere.

## The February notice requirement

The key safeguard appears in 10 U.S.C. §119. By 1 February each year, the Secretary of Defense must provide the congressional defence committees with a report covering every newly designated Special Access Program. The notice must include:

This last requirement is unusually revealing because it goes beyond ordinary budget reporting. Congress is not merely told that a programme exists; it is also given a framework for comparing it against the wider classified portfolio.

The reporting obligation complements, rather than replaces, the annual SAP budget reports that describe programme costs, milestones and projected spending. Together, these reports are intended to let oversight committees evaluate both the necessity of secrecy and the possibility that similar efforts already exist inside the defence establishment.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.law.cornell.edu/uscode/text/10/119" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: law.cornell.edu">[Legal Information Institute]</a><span class="citation-popover" role="note"><span class="citation-popover-source">law.cornell.edu</span><span class="citation-popover-title">Legal Information Institute10 U.S. Code § 119</span><span class="citation-popover-snippet">Special access programs: congressional oversight &#124; U.S. Code &#124; US Law &#124; LII / Legal Information Institute...</span></span></span>

## Why similar missions and technologies matter

In ordinary government programmes, duplication can often be identified through open budgets, published procurement plans or inter-agency coordination. Special Access Programs operate under much stricter controls, meaning that many officials—even those with high security clearances—may not know the details of programmes outside their authorised [compartments]({{ 'compartments/' | relative_url }}).

That creates a structural risk. Separate organisations may independently pursue technologies that:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* solve the same operational problem;
* rely on comparable scientific approaches;
* require overlapping industrial expertise; or
* duplicate testing and development already funded elsewhere.

</div>

The statutory requirement to identify programmes with similar missions or technologies gives congressional reviewers a starting point for asking difficult questions before additional resources are committed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.law.cornell.edu/uscode/text/10/119" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: law.cornell.edu">[Legal Information Institute]</a><span class="citation-popover" role="note"><span class="citation-popover-source">law.cornell.edu</span><span class="citation-popover-title">Legal Information Institute10 U.S. Code § 119</span><span class="citation-popover-snippet">Special access programs: congressional oversight &#124; U.S. Code &#124; US Law &#124; LII / Legal Information Institute...</span></span></span>

Importantly, "similar" does not necessarily mean "redundant". Two highly classified programmes may legitimately address the same mission through different technical approaches, serve different military services, or hedge against technological failure. The law therefore creates an opportunity for comparison rather than imposing an automatic prohibition on overlapping work.

## How compartmentation can hide waste as well as secrets

Compartmentation is designed to limit access to information strictly according to operational need. From a security perspective, this reduces the consequences of espionage or accidental disclosure. From a management perspective, however, the same barriers can impede visibility across organisations.

If programme managers cannot easily discover related classified work elsewhere, several forms of inefficiency become more likely:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* independent development of similar technologies;
* duplicate research contracts with different organisations;
* repeated testing of comparable concepts; and
* fragmented investment in capabilities that could potentially share infrastructure or expertise.

</div>

The February notice requirement attempts to counter this management problem without weakening operational security. Instead of opening programmes to broad visibility, it concentrates comparative information in the hands of the congressional committees already authorised to oversee classified defence spending.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.law.cornell.edu/uscode/text/10/119" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: law.cornell.edu">[Legal Information Institute]</a><span class="citation-popover" role="note"><span class="citation-popover-source">law.cornell.edu</span><span class="citation-popover-title">Legal Information Institute10 U.S. Code § 119</span><span class="citation-popover-snippet">Special access programs: congressional oversight &#124; U.S. Code &#124; US Law &#124; LII / Legal Information Institute...</span></span></span>

This reflects a broader principle of oversight: secrecy should limit [public disclosure]({{ 'public-disclosure/' | relative_url }}), not prevent authorised reviewers from recognising unnecessary overlap.

## What Congress can do with the comparison

Once defence committees receive notice of a proposed SAP and the accompanying comparison with existing programmes, members and cleared staff can examine several questions during classified oversight:


<div class="content-enhancement content-enhancement--comparison" markdown="1">

* Does the new programme genuinely require Special Access Program protection?
* Is there already a classified capability addressing substantially the same mission?
* Are multiple programmes pursuing parallel technological solutions for sound strategic reasons?
* Does the projected cost appear justified given existing investments?

</div>

These reviews occur inside classified oversight channels rather than public hearings. As a result, the public rarely sees whether committees conclude that a proposed programme is appropriately distinct or unnecessarily duplicative.

The reporting requirement therefore functions primarily as an internal [accountability]({{ 'accountability/' | relative_url }}) mechanism rather than a transparency measure. It equips authorised overseers with information that would otherwise remain scattered across separate classified compartments.

## A broader shift towards disciplined secrecy

The emphasis on identifying comparable programmes also fits wider concerns inside the defence establishment that Special Access Program status should be used selectively rather than routinely. Officials have acknowledged in other classified policy contexts that excessive compartmentation can restrict information sharing, complicate cooperation and create management inefficiencies even within the Department of Defense.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.law.cornell.edu/uscode/text/10/119" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: law.cornell.edu">[Legal Information Institute]</a><span class="citation-popover" role="note"><span class="citation-popover-source">law.cornell.edu</span><span class="citation-popover-title">Legal Information Institute10 U.S. Code § 119</span><span class="citation-popover-snippet">Special access programs: congressional oversight &#124; U.S. Code &#124; US Law &#124; LII / Legal Information Institute...</span></span></span>

The statutory notice requirement embodies that philosophy. Rather than treating every new classified programme as inherently unique, it requires decision-makers to demonstrate both why extraordinary secrecy is justified and how the programme relates to existing classified capabilities.

Within the broader system of congressional oversight of hidden defence programmes, this comparison requirement serves as a practical check against one of secrecy's less obvious hazards: allowing isolated compartments to evolve into parallel programmes that consume resources without decision-makers recognising the overlap.

        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
