## Introduction

Not every highly sensitive United States Department of Defense programme is managed as a classic Special Access Program (SAP). Over the past decade, Congress has recognised that some activities are instead protected through **Alternative Compensatory Control Measures (ACCMs)**—special handling systems designed to restrict access without formally designating a programme as a SAP. To prevent this becoming a route around congressional scrutiny, Congress created a parallel statutory oversight framework in **10 U.S.C. §119a**. Rather than focusing on the label attached to a programme, the law focuses on whether unusually restrictive control measures are being used and requires comparable reporting to the congressional defence committees.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section119a" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">June 21, 2026...</span><span class="citation-popover-meta">Published: June 21, 2026</span></span></span>

This represents an important evolution in oversight of hidden defence programmes. Instead of assuming that only SAPs require enhanced [accountability]({{ 'accountability/' | relative_url }}), Congress extended many of the same reporting obligations to programmes managed under ACCMs, reducing the possibility that administrative classifications alone could determine how much elected overseers are allowed to know.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section119a" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">June 21, 2026...</span><span class="citation-popover-meta">Published: June 21, 2026</span></span></span>

## What 10 U.S.C. §119a Adds

Section 119a was enacted to address programmes managed under **Alternative Compensatory Control Measures**, creating a statutory oversight regime that closely parallels the long-established rules governing SAPs under 10 U.S.C. §119. The underlying premise is straightforward: if a programme is sufficiently sensitive to require exceptional access restrictions, Congress should receive structured notification regardless of whether the programme carries the formal SAP designation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section119a" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">June 21, 2026...</span><span class="citation-popover-meta">Published: June 21, 2026</span></span></span>

Like the SAP statute, the law requires [annual reports]({{ 'annual-reports/' | relative_url }}) to the congressional defence committees that include:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* the total budget requested for ACCM-managed programmes;
* a brief description of each programme;
* major programme milestones;
* historical costs;
* estimated total programme costs; and
* projected future spending over multiple fiscal years.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section119a" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">June 21, 2026...</span><span class="citation-popover-meta">Published: June 21, 2026</span></span></span>

</div>

The statute also requires separate reporting on newly established ACCM-managed programmes. The Secretary of Defense must notify Congress of each new designation, explain why alternative controls are justified, provide current programme cost estimates, and identify comparable existing technologies or programmes. This mirrors the justification process already required for new SAPs and is intended to discourage unnecessary creation of additional highly compartmented programmes.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section119a" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">June 21, 2026...</span><span class="citation-popover-meta">Published: June 21, 2026</span></span></span>

## How the Reporting Structure Mirrors SAP Oversight

The most notable feature of Section 119a is how deliberately it tracks the existing SAP oversight model rather than inventing a separate system.

For ACCM-managed programmes, Congress receives requirements that closely resemble those applied to SAPs:

* **Annual budget reporting** using standardised information about programme scope and funding.
* **Advance notification of new programmes** together with written justification.
* **Reporting before declassification or major classification changes**, allowing Congress to understand planned [public disclosures]({{ 'public-disclosure/' | relative_url }}).
* **A general 30-day waiting period** before most new ACCM-managed programmes may begin, unless the Secretary determines that delaying initiation would cause exceptionally grave damage to national security.
* **Limited waiver authority**, allowing exceptionally sensitive details to be withheld only on a case-by-case basis while still providing the information directly to committee leadership together with the justification for withholding it.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section119a" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">June 21, 2026...</span><span class="citation-popover-meta">Published: June 21, 2026</span></span></span>

The legislative symmetry is significant. Congress did not simply acknowledge ACCMs as another security category; it deliberately subjected them to substantially the same accountability framework used for SAPs.

## Why Labels Matter for Congressional Scrutiny

The distinction between a SAP and an ACCM is administrative rather than a simple measure of sensitivity. SAPs are formal programmes established under long-standing Department of Defense policy with specialised [approval]({{ 'approval/' | relative_url }}) and management structures. ACCMs, by contrast, are alternative access-control mechanisms that may protect particularly sensitive information without placing the entire activity inside the traditional SAP framework.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section119a" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">June 21, 2026...</span><span class="citation-popover-meta">Published: June 21, 2026</span></span></span>

Without Section 119a, this distinction could have created a practical oversight gap. If reporting laws applied only to formally designated SAPs, agencies could theoretically protect information through alternative [compartmentation]({{ 'compartmentation/' | relative_url }}) systems while avoiding some of the reporting obligations attached to SAP status.

Congress addressed this possibility by tying oversight to the use of exceptional access controls rather than exclusively to programme nomenclature. In effect, the law reduces the incentive to rely on different administrative labels as a means of limiting routine congressional visibility.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section119a" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">June 21, 2026...</span><span class="citation-popover-meta">Published: June 21, 2026</span></span></span>

## The 2021 Expansion Beyond SAPs and ACCMs

Congress further reinforced this principle in the National Defense Authorization Act for Fiscal Year 2022 by adding subsection (g) to 10 U.S.C. §119a.

## Administrative Oversight Inside the Department of Defense

Congress paired reporting requirements with internal management responsibilities. Separate statutory authority requires the Secretary of Defense to designate a senior official as the Department's executive agent for management and oversight of ACCMs. That official is responsible for Department-wide accountability arrangements and an annual management and oversight plan supporting congressional reporting.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section430a" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">U.S. Code</span></span></span>

This reflects an important governance choice. Oversight is intended to occur both internally—through central management of alternative control systems—and externally through classified reporting to the congressional defence committees. The combination aims to reduce the risk that highly restricted programmes become fragmented across separate bureaucratic [compartments]({{ 'compartments/' | relative_url }}) without consistent accountability.

## Why Alternative Controls Became a Policy Issue

The creation of Section 119a illustrates a broader shift in congressional thinking about hidden defence programmes. Earlier oversight legislation concentrated primarily on formally designated SAPs. As security practices evolved, lawmakers recognised that highly compartmented activities might also be managed through alternative control systems.

Rather than attempting to abolish those systems, Congress extended oversight expectations to them. The result is not a requirement that every sensitive programme become a SAP, but a requirement that programmes receiving comparable extraordinary protection also receive comparable congressional scrutiny.

From the perspective of oversight, this represents a move away from focusing on administrative labels and towards focusing on the practical effect of extraordinary secrecy. If a programme is important enough to require exceptional access restrictions, Congress has increasingly insisted that it should also fall within a structured, statutory reporting framework, regardless of whether it is formally called a Special Access Program.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section119a" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-title">U.S. Code</span><span class="citation-popover-snippet">June 21, 2026...</span><span class="citation-popover-meta">Published: June 21, 2026</span></span></span>

    var url = template.replace('{query}', encodeQuery(query || '')).replace('{query_plain}', String(query || ''));
    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
